# Калькулятор — Биккулов Давид

Учебный проект для практических работ по разработке программного обеспечения.

## Возможности
- арифметические операции: сложение, вычитание, умножение, деление;
- поддержка скобок и приоритетов операций;
- математические функции: sqrt, sin, cos, tan, log, ln, abs, factorial;
- обработка некорректного ввода и деления на ноль.

## Запуск
Требуется Python 3.

```bash
python calculator_bikkulov.py
```
